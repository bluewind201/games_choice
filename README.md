# 렛츠고! 정상까지 (가제)

가상의 산 "구름바위산"을 오르며 길에서 만난 사람들과 버튼 3개짜리 미니게임으로 겨루고, 번 도토리로 산장에서 라이프와 장비를 사서 갈아입은 뒤, 정상에서 나만의 등산 패션 사진을 찍어 공유하는 2D 게임입니다.

- 플랫폼: PC (Steam, Windows 우선)
- 상태: 기획 단계
