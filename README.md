# 선택의 연속 (프로토타입)

상대의 숨겨진 성향(성격유형·혈액형·세대·띠·별자리)을 대화 속 단서로 추리하고, 말 한마디와 숏폼 미니게임으로 호감을 얻는 안드로이드용 오프라인 게임의 프로토타입입니다.

- 서버 없음: 모든 계산과 저장은 기기 안에서 합니다.
- 수익 모델: **보상형 광고만** 씁니다 (인앱결제·시즌 패스·꾸미기 없음). 광고는 언제나 선택 사항이고, 오프라인이면 버튼이 사라질 뿐 진행은 막히지 않습니다.
- 빌드 결과물: JS+CSS 약 55KB (gzip 약 25KB).

## 실행

```bash
npm install
npm run dev          # 브라우저에서 바로 플레이 (휴대폰과 같은 와이파이면 표시되는 주소로 접속)
npm test             # 상성 엔진·규칙·데이터 무결성 테스트
npm run build:single # dist/single.html 한 파일로 빌드 (오프라인에서 열어도 동작)
```

### 안드로이드 앱으로 빌드 (Capacitor)

Android Studio와 JDK 17이 있는 컴퓨터에서:

```bash
npm run android:add    # 처음 한 번: android/ 프로젝트 생성
npm run android:sync   # 웹 빌드를 앱에 반영
npx cap open android   # Android Studio에서 실행/APK 빌드
```

## 프로토타입 범위

| 구분 | 내용 |
| --- | --- |
| 온보딩 | 생년월일·혈액형 입력 → 띠·별자리(4원소)·세대 자동 산출, 12문항 성향 진단, 캐릭터 카드 |
| 페르소나 | 진짜 내 성향 대신 쓸 수 있는 페르소나 카드 3종 (궁합이 불리할 때 선택) |
| 스테이지 | STG_101 러닝크루 모임장(MBTI), STG_201 소개팅(+혈액형), STG_301 팀장(+세대) |
| 미니게임 | MG_402 집에 가고 싶은 본능 억제(MASH, Stop&Go), MG_602 진짜 이유 찾기(FIND), MG_101 결재서류 받기(CATCH) |
| 추리수첩 | 대화마다 관찰이 쌓이고, 상대 성향을 직접 체크. 정확도가 결정적 한마디의 위력과 결과에 반영 |
| 결정적 한마디 | 상대의 말에 맞는 증거를 골라 "잠깐만요!" 컷인 |
| 결과 | S/A/B/F 등급, 상대 정체 공개, 9:16 공유 카드 PNG (안드로이드 공유 시트) |
| 광고 | 미니게임 재도전, 배터리 +30, 추리 힌트 1개. 지금은 3초짜리 가짜 광고(`src/core/ads.ts`) |

## 미션 모드 (v0.2)

"상대 기분 맞추기"에서 벗어나, 상대를 읽고 **내 목표**를 이루는 버전입니다. 미션은 3개입니다 (`src/data/missions.ts`): Ch.1 "뒤풀이 탈출 작전"(뒤풀이는 빠지고 다음 주 총무 자리 따내기), Ch.2 "애프터 확정 작전"(토요일로 애프터 잡기), Ch.3 "6시 칼퇴 작전". 이전의 호감 올리기 버전은 지도 아래 "이전 버전"에 남아 있습니다.

- 게이지 3개: 🎯 미션 진행도(100 채우기), 😤 상대 인내심·여유·흥미(0이 되면 실패), ⏰ 시계(마감 시각을 넘기면 실패)
- 선택지마다 작전이 보입니다. 🙇 맞춰주기는 안전하지만 시간이 들고 미션이 안 나아가거나 오히려 후퇴합니다. ⚡ 밀어붙이기는 두 가지 방식 중 상대 성향에 맞는 쪽만 통하고, 틀리면 인내심이 상성 배율만큼 크게 깎입니다.
- 추리수첩은 "어떤 방식으로 밀어야 통하는지"를 알려주는 무기입니다.
- 결과: S(칼퇴 + 신뢰), A(칼퇴), B(칼퇴했지만 찍힘), F(인내심 폭발 / 시간 초과 / 일이 남음)
- 균형: 전부 정확히 읽으면 S, 한 번 맞춰주기까지는 클리어 가능, 맞춰주기만 하면 실패 (`tests/mission.test.ts`에서 검사)

## 2D 레트로 동네 모드 (v0.4)

캐릭터를 만들고 나면 위에서 내려다보는 2D 도트 동네에서 하루를 보냅니다 (`src/world/`, Canvas 2D, 외부 라이브러리 없음). v0.3의 3D 버전은 2D로 바꿨습니다. 대화 미션은 동네 안의 일정으로 들어갑니다.

- 이동: 화면 왼쪽 아래 조이스틱 (PC는 WASD/방향키, 상호작용은 Space/E). 가까이 가면 오른쪽 아래에 행동 버튼이 뜹니다.
- 지도: 왼쪽 위 미니맵(주변 40칸)과, 누르면 열리는 전체 지도(장소 이름, 미션 🎯·퀘스트 ❗·상점 🛒 위치, 지금 목표). 목표가 화면 밖이면 가장자리에 화살표와 거리가 뜹니다. PC는 M 키.
- 하루 시계: 현실 1초 = 게임 4분. 9시 전 회사 앞 출근, 16:50 박 팀장 "6시 칼퇴 작전", 19:00 지우 "애프터 확정 작전", 20:00 하나 "뒤풀이 탈출 작전". 시간이 지나면 그날은 못 하고 다음 날 다시 합니다. 21시 이후 집 앞에서 자면 다음 날 (배터리 100), 자정까지 안 자면 배터리 60으로 시작.
- 돌발 만남: 돌아다니는 택배 기사님, 윗집 이웃, 전단지 알바생과 부딪치면 짧은 선택 이벤트 (하루 한 번씩).
- 서브 퀘스트: 공원의 떨어진 지갑을 옆집 할머니께 (1만 원), 동네 고양이 3마리 찾기 (고양이 귀 머리띠).
- 성장: 미션 보상 S 3만 원/120XP, A 2만 원, B 1만 원, 실패 20XP. 레벨 = 100×Lv XP. 레벨이 오르면 편의점·옷가게에 새 옷이 열립니다.
- 꾸미기: 게임 머니로 옷·모자·안경·염색·가방을 사서 옷장에서 갈아입습니다. 실제 돈 결제는 없습니다 (수익은 보상형 광고만).
- 저장: `SaveData.world` (위치, 시각, 레벨, 돈, 옷, 플래그).

## 대화 연출과 디자인 (v0.5)

- 대화 장면: 장소별 도트 배경(회사, 파스타 가게, 밤 공원) 위에 말하는 사람의 큰 도트 초상화가 나옵니다 (`src/ui/portrait.ts`, `src/ui/scene.ts`). 표정 6가지(보통, 기쁨, 당황, 화남, 의심, 서운)가 대사마다 바뀌고, 말하는 동안 입이 움직이며 가끔 눈을 깜빡입니다. 내가 말할 때는 내 캐릭터(옷장에서 꾸민 모습)로 바뀝니다.
- 글자: 한 글자씩 찍히고 글자마다 효과음이 납니다. "!"로 끝나는 문장이나 `*별표*`로 감싼 부분은 크게 찍히고, 문장이 끝나면 화면이 흔들리고 진동합니다 (`src/ui/dialogue.ts`). 대사를 누르면 바로 다 나옵니다. 장면 오른쪽 위 🔊로 소리를 끌 수 있습니다.
- 동네 대화, 돌발 만남, 미션 시작 인사도 같은 대화창을 씁니다.
- 디자인: 도트 글꼴 Galmuri11 (OFL, `src/assets/fonts/`), 굵은 테두리와 각진 그림자, 도트 동네가 깔린 타이틀 화면.
- 새 미니게임 3개는 동네 활동(하루 한 번씩)으로 넣었습니다: MG_701 말 끊기 타이밍(오전 회의, 09~12시, 출근한 날), MG_702 주문 기억하기(카페 알바, 10~16시, 최대 9,000원), MG_703 표정 읽기(공원 벤치 사람 구경, 배터리 회복).

## 확정한 설계 규칙

모든 수치는 `src/core/rules.ts`와 `src/core/compat.ts`에 있습니다.

**선택지 3개** (화면에는 종류가 표시되지 않고, 고른 뒤에 알려줌)

| 종류 | 호감 | 배터리 | 의미 |
| --- | --- | --- | --- |
| 공략 | +14~15 | -6 × 상성 배율 | 상대 성향을 정확히 읽은 말. 어느 게 공략인지 추리해야 함 |
| 사회생활 가면 | +5~8 | -12 × 상성 배율 | 누구에게나 무난한 말. 배터리를 많이 씀 |
| 본심 | -10~-12 | +4 | 내 마음대로. 배터리 회복 |

**클리어 기준**: 호감 0~100. 대화가 끝날 때 호감 70 이상이면 클리어.
S = 호감 90 이상 + 배터리 40 이상, A = 호감 80 이상, B = 70 이상, F = 그 아래 또는 배터리 0(번아웃).

**사회적 배터리**: 100에서 시작해 스테이지 사이에 이어지고, 스테이지가 끝날 때마다 +25 회복. 지도에서 "하루 새로 시작"으로 100으로 되돌릴 수 있음.

**상성 수치 기준**: 03 DB 마스터시트를 정본으로 쓰고, 시트에 없는 조합은 GDD 규칙으로 채움.
- 초기 호감 = clamp(50 + 해금된 레이어 보정 합, 20, 80)
- 배터리 배율 = clamp(1 + Σ(레이어 배율 − 1), 0.6, 2.0) — 곱하지 않고 더해서 폭주를 막음
- 별자리는 **4원소 규칙만** 사용: 불-공기 +10, 흙-물 +10, 불-물 -10, 흙-공기 -8, 같은 원소 +5, 나머지 0
- 12지신: 삼합 +15, 육합 +10, 원진살 -12, 상충살 -15
- 띠는 양력 연도 기준으로 단순화 (1~2월생의 음력 설 경계는 추후 반영)

**미니게임 보상**: 대성공 호감 +16 & 배터리 +8, 성공 +12, 실패 -12. 상대가 상극(어느 레이어든 -12 이하)이면 방해물이 늘어남. 속도형 성향(ESTJ·ENTJ·ESTP, B형·O형)이면 속도 +20%, 제한시간 +1초.

**결정적 한마디**: 맞는 증거 제시 시 호감 +10 + 15 × 추리 정확도. 틀리면 호감 -8, 배터리 -15.

## 콘텐츠 추가 방법
