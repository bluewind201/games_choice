# 선택의 연속 (프로토타입)

상대의 숨겨진 성향(성격유형·혈액형·세대·띠·별자리)을 대화 속 단서로 추리하고, 말 한마디와 숏폼 미니게임으로 호감을 얻는 안드로이드용 오프라인 게임의 프로토타입입니다.

- 서버 없음: 모든 계산과 저장은 기기 안에서 합니다.
- 수익 모델: **보상형 광고만** 씁니다 (인앱결제·시즌 패스·꾸미기 없음). 광고는 언제나 선택 사항이고, 오프라인이면 버튼이 사라질 뿐 진행은 막히지 않습니다.
- 빌드 결과물: JS+CSS 약 55KB (gzip 약 25KB).

## 실행

```bash
npm install
npm run dev          # 브라우저에서 바로 플레이 (휴대폰과 같은 와이파이면 표시되는 주소로 접속)
npm test             # 상성 엔진·규칙·데이터 무결성 테스트
npm run build:single # dist/single.html 한 파일로 빌드 (오프라인에서 열어도 동작)
```

### 안드로이드 앱으로 빌드 (Capacitor)

Android Studio와 JDK 17이 있는 컴퓨터에서:

```bash
npm run android:add    # 처음 한 번: android/ 프로젝트 생성
npm run android:sync   # 웹 빌드를 앱에 반영
npx cap open android   # Android Studio에서 실행/APK 빌드
```

## 프로토타입 범위

| 구분 | 내용 |
| --- | --- |
| 온보딩 | 생년월일·혈액형 입력 → 띠·별자리(4원소)·세대 자동 산출, 12문항 성향 진단, 캐릭터 카드 |
| 페르소나 | 진짜 내 성향 대신 쓸 수 있는 페르소나 카드 3종 (궁합이 불리할 때 선택) |
| 스테이지 | STG_101 러닝크루 모임장(MBTI), STG_201 소개팅(+혈액형), STG_301 팀장(+세대) |
| 미니게임 | MG_402 집에 가고 싶은 본능 억제(MASH, Stop&Go), MG_602 진짜 이유 찾기(FIND), MG_101 결재서류 받기(CATCH) |
| 추리수첩 | 대화마다 관찰이 쌓이고, 상대 성향을 직접 체크. 정확도가 결정적 한마디의 위력과 결과에 반영 |
| 결정적 한마디 | 상대의 말에 맞는 증거를 골라 "잠깐만요!" 컷인 |
| 결과 | S/A/B/F 등급, 상대 정체 공개, 9:16 공유 카드 PNG (안드로이드 공유 시트) |
| 광고 | 미니게임 재도전, 배터리 +30, 추리 힌트 1개. 지금은 3초짜리 가짜 광고(`src/core/ads.ts`) |

## 확정한 설계 규칙

모든 수치는 `src/core/rules.ts`와 `src/core/compat.ts`에 있습니다.

**선택지 3개** (화면에는 종류가 표시되지 않고, 고른 뒤에 알려줌)

| 종류 | 호감 | 배터리 | 의미 |
| --- | --- | --- | --- |
| 공략 | +14~15 | -6 × 상성 배율 | 상대 성향을 정확히 읽은 말. 어느 게 공략인지 추리해야 함 |
| 사회생활 가면 | +5~8 | -12 × 상성 배율 | 누구에게나 무난한 말. 배터리를 많이 씀 |
| 본심 | -10~-12 | +4 | 내 마음대로. 배터리 회복 |

**클리어 기준**: 호감 0~100. 대화가 끝날 때 호감 70 이상이면 클리어.
S = 호감 90 이상 + 배터리 40 이상, A = 호감 80 이상, B = 70 이상, F = 그 아래 또는 배터리 0(번아웃).

**사회적 배터리**: 100에서 시작해 스테이지 사이에 이어지고, 스테이지가 끝날 때마다 +25 회복. 지도에서 "하루 새로 시작"으로 100으로 되돌릴 수 있음.

**상성 수치 기준**: 03 DB 마스터시트를 정본으로 쓰고, 시트에 없는 조합은 GDD 규칙으로 채움.
- 초기 호감 = clamp(50 + 해금된 레이어 보정 합, 20, 80)
- 배터리 배율 = clamp(1 + Σ(레이어 배율 − 1), 0.6, 2.0) — 곱하지 않고 더해서 폭주를 막음
- 별자리는 **4원소 규칙만** 사용: 불-공기 +10, 흙-물 +10, 불-물 -10, 흙-공기 -8, 같은 원소 +5, 나머지 0
- 12지신: 삼합 +15, 육합 +10, 원진살 -12, 상충살 -15
- 띠는 양력 연도 기준으로 단순화 (1~2월생의 음력 설 경계는 추후 반영)

**미니게임 보상**: 대성공 호감 +16 & 배터리 +8, 성공 +12, 실패 -12. 상대가 상극(어느 레이어든 -12 이하)이면 방해물이 늘어남. 속도형 성향(ESTJ·ENTJ·ESTP, B형·O형)이면 속도 +20%, 제한시간 +1초.

**결정적 한마디**: 맞는 증거 제시 시 호감 +10 + 15 × 추리 정확도. 틀리면 호감 -8, 배터리 -15.
