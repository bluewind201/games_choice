# 3D 변환용 기준 그림 (2026-11-27, Google Flow · Nano Banana 2.1)

정면 A자 포즈, 흰 배경. AI 이미지→3D 변환(Meshy/Tripo) 입력용입니다. `*-square.png`는 캐릭터만 잘라 1024×1024로 맞춘 업로드용 파일이에요.

| 파일 | 캐릭터 | 메모 |
|---|---|---|
| m1, m2 | 남자 주인공 | m1이 3등신에 더 가까워 추천 |
| f1, f2 | 여자 주인공 | 둘 다 사용 가능 |
| u1, u2 | 등산 아저씨 | 스틱은 3D 변환 때 손과 붙어 뼈대가 꼬일 수 있어, 스틱 없는 버전이 필요할 수 있음 |
