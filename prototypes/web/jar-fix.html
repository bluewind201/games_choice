깨진 항아리 막기

4구간 「능선 산장」 · 콩쥐 사장님: "팥쥐가 깨 놓은 항아리에 물을 채워야 손님 라면을 끓여!" (게임성 테스트용, 그림은 임시)

하는 법 · 시작은 Space 또는 화면 클릭
  • 콩쥐 사장님이 물을 붓는 동안, 항아리 왼쪽·가운데·오른쪽에 금이 가며 물이 새요. 해당 버튼을 누르면 두꺼비가 구멍을 막아 줍니다.
  • 두꺼비는 오래 못 버텨요. 두꺼비 머리 위 동그라미가 다 줄면 폴짝 내려가고 구멍이 다시 열려요. 다시 눌러 막아 주세요.
  • 큰 구멍(물이 콸콸)은 두 번 눌러야 막혀요. 구멍 없는 곳을 누르면 두꺼비가 헛디뎌 물이 조금 쏟아집니다.
  • 30초 안에 물을 빨간 선까지 채우면 성공. 실패하면 라이프가 1개 깎입니다.
